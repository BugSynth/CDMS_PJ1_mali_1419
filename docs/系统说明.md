# 系统说明

## 1. 系统目标

本系统是基于MongoDB的在线问卷系统。注册用户可以创建、保存和发布问卷，通过链接收集答卷，并查看实时统计。系统保留第一阶段的问卷填写、条件跳转、服务端校验和统计能力；第二阶段在原有结构上增加题库、题目版本、题目共享、题目使用关系、跨问卷统计和问卷库。

## 2. 用户与权限

用户通过用户名和密码注册、登录。登录后取得令牌，管理接口依据令牌解析用户身份。用户只能管理自己的问卷、题库、题目版本和问卷模板；已获共享授权的题库或题目版本可被查询和复用，但不能被接收方修改或删除。填写已发布问卷时仍由服务端判断是否允许匿名填写、是否截止及是否允许重复提交。

## 3. 功能模块

| 模块 | 功能 |
| --- | --- |
| 账号模块 | 注册、登录、令牌认证和用户隔离 |
| 问卷模块 | 创建草稿、编辑题目与规则、发布、关闭、删除、分享链接和统计 |
| 填写模块 | 按题序填写、按规则跳转、即时提示、提交前服务端复核和答卷保存 |
| 题目库模块 | 创建题库、保存可复用题目、按题库筛选、共享题目和查看使用关系 |
| 版本模块 | 为同一逻辑题创建命名版本、查看历史和来源、切换当前版本、删除单个版本或整题 |
| 问卷库模块 | 从草稿保存整份问卷模板、查看和删除模板、基于模板复制新草稿 |
| 统计模块 | 查询单份问卷统计和题目跨问卷统计，区分回答、访问、跳过和未答 |

## 4. 系统架构

```text
浏览器HTML/CSS/JavaScript
  ├─问卷编辑、题目库、问卷库、统计、功能验证
  └─填写页
        ↓HTTP+JSON
Node.js原生HTTP服务
  ├─认证与权限检查
  ├─问卷、题库、模板和答卷业务逻辑
  ├─校验、跳转路径计算和统计聚合
        ↓MongoDBNode.jsDriver
MongoDB九个业务集合
```

前端只负责交互和即时反馈；是否有权限、题目答案是否有效、访问路径是否符合跳转规则均由服务端再次判断。MongoDB保存业务事实数据，服务重启不会丢失用户、问卷、题目或答卷。

## 5. 关键业务流程

1. 创建者新建问卷，配置题目、校验条件和跳转规则，保存草稿或发布。
2. 填写者打开发布链接，按当前题目的规则继续填写；前端显示下一题，但提交时服务端重新计算路径。
3. 服务端验证答案、访问路径、必答条件和问卷状态，成功后写入答卷头与逐题答案。
4. 创建者读取统计，服务端从答卷和答案事实数据聚合结果。
5. 可复用题目先保存在题库中。修改题目生成同一逻辑题的新版本，已有问卷仍保存原题目快照。
6. 草稿可保存为问卷库模板；使用模板时复制为新的草稿，模板、源草稿和新草稿互不回写。

## 6. 运行说明

运行环境为Node.js20+和本地MongoDB7+。复制`.env.example`为`.env`后执行`npm.cmd install`、`npm.cmd run db:init`和`npm.cmd start`。默认访问地址为`http://localhost:3002`。详细接口见[API说明.md](API说明.md)，数据集合见[数据库设计.md](数据库设计.md)。
